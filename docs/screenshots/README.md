# Screenshots

These images are shown in the README once they are added to this folder. Capture them at **1280×800** (or 1920×1200 and downscale), dark theme.

## Checklist

| File | What to capture |
| --- | --- |
| `home.png` | Home page with the goal form (title, duration, daily hours) |
| `overview.png` | Plan overview: progress track + milestone cards |
| `daily.png` | Daily tasks with the calendar sidebar |
| `verification.png` | Verification modal with a quiz |
| `tutor.png` | AI tutor chat with the stage pipeline and streaming reply |

## Workflow

1. Create a goal such as “Learn JavaScript closures” with a 10-day duration.
2. Open the plan overview and capture `overview.png`.
3. Open daily tasks and capture `daily.png`.
4. Open a learning task, start the tutor, send a message, and capture `tutor.png` while the reply streams.
5. Open verification and capture `verification.png`.

Once the files exist here, they can be referenced from the README as `docs/screenshots/<name>.png`.

## Demo GIF

The README showcases a short demo recording (`docs/screenshots/demo.gif`). To create it:

1. Run the app locally, then record 15–30 seconds covering the main flow: home → create a goal → plan overview → daily tasks → tutor chat.
2. On Windows use `Win + Alt + R` (Xbox Game Bar); save the recording as `docs/screenshots/demo.mp4`.
3. Send the recording to the maintainer, who will convert it to `docs/screenshots/demo.gif` (resized to 900px wide, ~12 fps).
